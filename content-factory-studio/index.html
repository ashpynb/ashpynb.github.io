Content Factory Studio

Content Factory Studio is a desktop app that runs on the creator's own Windows computer. It helps a creator cut long videos they have the rights to use into short vertical clips, add captions and a title, and schedule them.

With the creator's permission (TikTok Login Kit), the app sends finished clips to the creator's own TikTok account as drafts (Content Posting API, video.upload), so the creator can review, edit and post them in the TikTok app.

The app has no server: videos, settings and access tokens stay on the creator's computer.
